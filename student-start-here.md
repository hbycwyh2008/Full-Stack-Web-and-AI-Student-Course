# Student Start Here

Open this file first. It tells you what to do today, where your work goes, and what to submit.

## Today

1. Open the class mission your teacher assigned: [class-missions/](class-missions/README.md).
2. Read the mission from top to bottom before you start.
3. Use the required resource only for the first learning block.

5. Submit the evidence listed in the mission.

## Submit Evidence

Use the evidence level named in your mission:

- Daily Evidence: small proof from today.
- Phase Checkpoint Evidence: working artifact plus README, commits, reflection, and AI usage note if used.
- Final Project Evidence: House Price or MNIST demo, full documentation, testing table, revision history, portfolio page, model limitation note, and AI usage documentation.

Read: [evidence-levels.md](evidence-levels.md) and [submission-guide.md](submission-guide.md).

## If You Are Stuck

1. Read the error message slowly.
2. Check the mission's Common Problems section.
3. Compare your file names and folders with the mission.
4. Ask your group using Talk Robin.
5. Ask AI for a hint or explanation, not a full answer.
6. Ask the teacher and show what you already tried.

Use: [student-troubleshooting-guide.md](student-troubleshooting-guide.md).

## Mastery Standard

Running code once is not enough. Mastery means you can explain, rebuild, debug, modify, and apply the pattern.

## AI Rule

AI is allowed for hints, explanation, debugging, and review. You cannot submit AI-generated work you cannot explain. A machine learning model cannot replace your own explainable student-written logic. See [ai-use-policy.md](ai-use-policy.md).
