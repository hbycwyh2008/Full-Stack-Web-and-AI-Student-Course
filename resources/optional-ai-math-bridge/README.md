# Optional AI Math Bridge

This is an optional / teacher-selected extension. It is not required before HTML/CSS, JavaScript, React, Next.js, or FastAPI.

Use these lessons when the class is ready to connect AI ideas to vectors, matrices, similarity, image data, or simple numerical reasoning.

## Suggested Use

- Pick one mini lesson when it supports the capstone.
- Do not use this as a blocker before web development.
- Keep evidence lightweight unless the teacher assigns a checkpoint.
