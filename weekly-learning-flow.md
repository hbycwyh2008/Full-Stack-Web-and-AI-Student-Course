# Weekly Learning Flow

Each 90-minute class uses the same learning rhythm.

| Time | What happens | Student job |
|---|---|---|
| 0-10 min | Entry Point Check | Answer what you already know and where you are stuck |
| 10-25 min | Individual Learning | Use one required resource and take short notes |
| 25-35 min | Talk Robin | Everyone speaks once before anyone speaks twice |
| 35-45 min | Group Answer | Prepare one shared answer or stuck-point list |
| 45-55 min | Teacher Clarification | Listen for the exact stuck points the teacher explains |
| 55-75 min | Mission Task | Build the required artifact |
| 75-85 min | Independent Rebuild | Rebuild or explain without copying |
| 85-90 min | Submit Evidence | Submit the evidence listed in the mission |

If a video or course activity is longer than the class block, finish only the assigned section in class. The rest becomes homework or later practice.
