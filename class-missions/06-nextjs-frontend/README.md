# Next.js Frontend Mini-Unit

Build a small Next.js App Router app in `nextjs-practice/` — setup, routing, layouts, client components, and dynamic routes.

## Unit Goal

By the end of this unit (when your teacher assigns it), each student should be able to:

- Create a Next.js project with `create-next-app` and App Router
- Add multiple routes, a shared layout, and `next/link` navigation
- Use `'use client'` for interactive UI and one dynamic route segment
- Submit evidence linking `react-practice/` and `nextjs-practice/`

> **CS1 note:** Core front-end teaching uses **React + Vite** in [Unit 05](../05-react-basics/react-lessons/). This unit is **teacher-assigned extension** unless your school makes Next.js required. See [course-map.md](../../course-map.md).

## Prerequisites

Complete [React Basics](../05-react-basics/react-lessons/) first — especially [Lesson 7](../05-react-basics/react-lessons/lesson-07-useeffect-and-fetch.md). Keep `react-practice/`; start a **new** folder `nextjs-practice/`.
