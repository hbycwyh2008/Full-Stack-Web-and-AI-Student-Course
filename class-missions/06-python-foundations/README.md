# Unit 3: Python Foundations

**Purpose:** Students learn enough Python to understand data processing and machine learning projects.

Keep lessons practical and task-based. Do not turn this into a full Python textbook.

## Core Topics

- variables
- `if/else`
- loops
- lists
- dictionaries
- functions
- file reading
- basic debugging
- simple testing

## Recommended Resources

- Michigan Python for Everybody as a reference
- Kaggle Python as practical exercises
- Do not use IBM Python courses as the main resource

## Suggested Lessons

| Lesson | Focus | Evidence |
|---|---|---|
| 1 | variables and output | small Python file |
| 2 | `if/else` decisions | recommendation function |
| 3 | loops and lists | process several values |
| 4 | dictionaries | represent one record |
| 5 | functions and simple tests | test table |
| 6 | file reading preview | read a small file |
| 7 | no-notes mastery check | input → logic → output task |
