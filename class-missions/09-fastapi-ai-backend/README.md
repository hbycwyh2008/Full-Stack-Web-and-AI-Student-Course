# Unit 6: FastAPI Backend for AI Apps

**Purpose:** Students understand how React communicates with a Python backend.

## Include

- FastAPI route
- GET / POST
- request body
- response JSON
- Pydantic model
- CORS basics
- calling Python functions
- calling a trained model
- returning prediction results

## Do Not Teach in CS1

- database
- authentication
- Docker
- cloud deployment
- complex backend architecture

## Core Flow

```text
React frontend collects user input
→ fetch() sends JSON
→ FastAPI receives request
→ Python function or ML model predicts
→ FastAPI returns JSON
→ React displays result
```
