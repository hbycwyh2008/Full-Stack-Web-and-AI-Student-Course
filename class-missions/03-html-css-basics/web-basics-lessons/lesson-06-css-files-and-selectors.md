# Lesson 4: Images and HTML Practice

## Lesson Goal

By the end of this lesson, each student should be able to:

1. Add at least one image with meaningful `alt` text.
2. Explain how `src` and `alt` work on an `<img>` tag.
3. Apply HTML skills from Lessons 1–3 in a short practice block.
4. Fix one image or markup problem without reopening the tutorial.
5. Submit daily evidence listed below.

## Required Resource

Open only the resource named in `Individual Learning`. Item 14 fits the 15-minute class block; item 15 may continue into Guided Practice or homework.

## What to Focus On

**Today's pattern:** images, `src`, `alt`, and HTML practice. Internal and external CSS come in [Lesson 5](lesson-11-css-internal-external-stylesheets.md).

## Entry Point Check (0–10 min)

- Where should image files live in `web-basics-project/`?
- What should `alt` text describe?
- What HTML from earlier lessons should I reuse today?

## Individual Learning (10–25 min)

> [!NOTE]
> **One required resource** for this block — see below. Do not browse extra HTML tutorials during class.

**Required resource — [HTML & CSS Crash Course, Module 1](https://www.coursera.org/learn/html--css-crash-course/home/module/1)** (Kevin Powell / Scrimba).

**Class time target:** watch **item 14** during the 10–25 minute block (~8 min). Start **item 15** only if time remains; finish item 15 during Guided Practice or as homework.

| Coursera item # | Title | ~Time | When to use |
|---|---|---|---|
| 14 | Images | 8 min | **Core in class** |
| 15 | Practice time! | 24 min | Start in class; finish in practice or homework |

**Stop here for new topics.** Do **not** open item 16 (Internal CSS) during this class — stylesheet linking starts in [Lesson 5](lesson-11-css-internal-external-stylesheets.md).

**Map the course to this project:**

| Course concept | What to add to `web-basics-project/` |
|---|---|
| Image tag | One `<img>` with `src` and `alt` |
| File path | Keep images in `web-basics-project/` or an `images/` subfolder |
| Alt text | Describe the image for accessibility |
| HTML practice | Reuse headings, links, lists, and paragraphs from earlier lessons |

## Guided Practice (55–75 min)

1. Open `web-basics-project/index.html`.
2. Add one meaningful image with `src` and `alt`.
3. Confirm the image loads in the browser.
4. Continue Coursera item 15 practice on your own page if you did not finish it in Individual Learning.
5. Fix one broken path, missing `alt`, or markup issue you notice.
6. Commit with message: `Add image and HTML practice updates`.

## Exit Check (75–85 min)

Close Coursera. Improve `alt` text or fix one image path without reopening the tutorial.

## Evidence to Submit (85–90 min)

1. Screenshot of the page with a visible image
2. GitHub link to updated `index.html`
3. Screenshot or link showing today's commit
4. One sentence: "`alt` text helps because..."
