# Lesson 6: HTML Tags Review

## Lesson Goal

By the end of this lesson, each student should be able to:

1. Name the most useful HTML tags used so far in this project.
2. Explain what each tag is for in their own words.
3. Point to examples of those tags in `index.html`.
4. Submit daily evidence listed below.

## Required Resource

Open only the resource named in `Individual Learning`. The assigned Coursera viewing is about 3 minutes.

## What to Focus On

**Today's pattern:** tag review before box model work. Classes and comments continue in [Lesson 7](lesson-07-css-classes-ids-and-comments.md).

## Guided Practice (55–75 min)

1. Open `web-basics-project/index.html`.
2. Label or comment three tags you already used (`h1`, `p`, `a`, `ul`, `img`, etc.).
3. Confirm each tag has a clear purpose on the page.
4. Commit with message: `Review core HTML tags in web basics page`.

## Exit Check (75–85 min)

Close Coursera. Name three HTML tags on your page and what each one does.

## Evidence to Submit (85–90 min)

1. Screenshot of your page or code showing three core tags
2. GitHub link to `index.html`
3. One sentence: "The most useful tag on my page is ___ because..."
