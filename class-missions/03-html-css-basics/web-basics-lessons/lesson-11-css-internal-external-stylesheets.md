# Lesson 5: Internal and External CSS

## Lesson Goal

By the end of this lesson, each student should be able to:

1. Explain the difference between internal CSS and external CSS.
2. Link `style.css` from `index.html`.
3. Move project styling into the external stylesheet.
4. Confirm styling appears after refreshing the browser.
5. Submit daily evidence listed below.

## Required Resource

Open only the resource named in `Individual Learning`. The assigned Coursera viewing is under 25 minutes.

## What to Focus On

**Today's pattern:** stylesheet location, `<link rel="stylesheet">`, and keeping CSS out of inline HTML. Classes and comments come in [Lesson 7](lesson-07-css-classes-ids-and-comments.md).

## Entry Point Check (0–10 min)

- Where does HTML structure live?
- Where should CSS style live in this project?
- What file should I create or open first?

## Guided Practice (55–75 min)

1. Open `web-basics-project/index.html`.
2. Create or open `web-basics-project/style.css`.
3. Link the stylesheet from `<head>`.
4. Move or add at least two CSS rules in `style.css`, such as `body` and `h1`.
5. Refresh the browser and confirm the rules are visible.
6. Commit with message: `Link external CSS stylesheet`.

## Exit Check (75–85 min)

Close Coursera. Change one CSS value in `style.css`, refresh, and explain why the HTML file did not need inline styles.

## Evidence to Submit (85–90 min)

1. Screenshot of the styled page
2. GitHub links to `index.html` and `style.css`
3. Screenshot or link showing today's commit
4. One sentence: "External CSS helps because..."
