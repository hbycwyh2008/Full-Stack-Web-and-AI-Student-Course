# Lesson 9: Box Model Wrap-Up and Basic Layout

## Lesson Goal

By the end of this lesson, each student should be able to:

1. Explain the full box model in one sentence.
2. Build a readable centered layout with a page container.
3. Use `max-width` and `margin: 0 auto` on a container.
4. Test the page in wide and narrow browser widths.
5. Submit daily evidence listed below.

## Required Resource

Open only the resource named in `Individual Learning`. Total viewing is about 28 minutes — finish item 26 as homework only if you run out of class time.

## What to Focus On

**Today's pattern:** box model review, basic page layout, and centered container. Flexbox starts in [Lesson 10](lesson-04-flexbox-mini-project.md).

## Entry Point Check (0–10 min)

- What is padding vs margin?
- Is my page too wide or hard to read?
- Which element should become the main container?

## Guided Practice (55–75 min)

1. Open `style.css` and DevTools; inspect one element from [Lesson 8](lesson-03-box-model-and-layout.md).
2. Add `class="page-container"` to `<main>` or a wrapper element.
3. Set `max-width: 720px` and `margin: 0 auto` on the container.
4. Add consistent spacing between cards or sections.
5. Test in a wide window and a narrow window — fix any horizontal scroll.
6. Commit with message: `Add centered layout and box model review`.

## Exit Check (75–85 min)

Close Coursera. Adjust one width, margin, or padding value until the layout is easier to read.

## Evidence to Submit (85–90 min)

1. Screenshot of the centered layout
2. Screenshot of DevTools box model inspection
3. GitHub links to updated `index.html` and `style.css`
4. One sentence: "`margin: 0 auto` helps because..."
