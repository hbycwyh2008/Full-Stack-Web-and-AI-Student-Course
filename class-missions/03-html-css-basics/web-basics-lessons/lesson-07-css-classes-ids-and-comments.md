# Lesson 7: CSS Classes and Comments

## Lesson Goal

By the end of this lesson, each student should be able to:

1. Use one class selector and one id selector correctly.
2. Explain when a class is better than an id.
3. Add a helpful comment in HTML or CSS.
4. Improve the style of the existing page without inline CSS.
5. Submit daily evidence listed below.

## Required Resource

Open only the resource named in `Individual Learning`. The assigned Coursera viewing is under 25 minutes.

## What to Focus On

**Today's pattern:** reusable classes, one unique id, and readable CSS comments.

## Entry Point Check (0–10 min)

- Which styles should repeat on more than one element?
- Which page element is unique?
- What selector confused me last lesson?

## Guided Practice (55–75 min)

1. Open `index.html` and `style.css`.
2. Add `class="card"` to at least two sections.
3. Add `id="tagline"` to one paragraph or heading.
4. Style `.card` and `#tagline` in `style.css`.
5. Add one short comment if it clarifies your CSS.
6. Commit with message: `Add CSS classes and id selectors`.

## Exit Check (75–85 min)

Close Coursera. Point to one class selector and one id selector in your code. Change one value without reopening the tutorial.

## Evidence to Submit (85–90 min)

1. Screenshot of the updated page
2. GitHub links to `index.html` and `style.css`
3. Screenshot or link showing today's commit
4. One sentence: "A class is useful when..."
