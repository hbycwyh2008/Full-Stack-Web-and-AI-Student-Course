# Lesson 2: HTML Text, File Names, and Links

## Lesson Goal

By the end of this lesson, each student should be able to:

1. Use text emphasis tags intentionally.
2. Add at least one working link.
3. Explain why clear file names and folder organization matter.
4. Explain what changed without reopening the tutorial.
5. Submit daily evidence listed below.

## Required Resource

Open only the resource named in `Individual Learning`. The assigned Coursera viewing is under 25 minutes.

## What to Focus On

**Today's pattern:** text emphasis, file naming, anchor links, and attributes. Lists come in [Lesson 3](lesson-02-css-basics-and-selectors.md); images come in [Lesson 4](lesson-06-css-files-and-selectors.md).

## Entry Point Check (0–10 min)

- What content on my page needs a link?
- What HTML tag do I already know from Lesson 1?
- What is one question I need answered before building?

## Guided Practice (55–75 min)

1. Open `web-basics-project/index.html`.
2. Check that `index.html` is inside `web-basics-project/` and named clearly.
3. Add one meaningful link.
4. Use `<strong>` or `<em>` once where it helps the meaning.
5. Refresh the browser and test the link.
6. Commit with message: `Add link and text emphasis to web basics page`.

## Exit Check (75–85 min)

Close Coursera. Revise one link label or emphasized phrase in your own words.

## Evidence to Submit (85–90 min)

1. Screenshot of the updated page
2. GitHub link to `web-basics-project/index.html`
3. Screenshot or link showing today's commit
4. One sentence: "My link works because..."
