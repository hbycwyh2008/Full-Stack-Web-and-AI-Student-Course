# Web Basics: HTML and CSS Mini-Unit

Build a simple, complete static webpage across multiple 90-minute class missions.

## Unit Goal

By the end of this unit, each student should be able to build and submit a small static page with HTML structure, external CSS, container layout, and Flexbox alignment.

Work in one folder — `web-basics-project/` — and grow the same project across the lesson sequence.

## Prerequisites

Complete [GitHub + Notion](../../01-github-notion/) first. You should already have:

- A personal course repository on GitHub
- A code editor and browser ready for local files

## CS1 Scope Limits

This unit is part of the front-end foundation. Keep it practical and small:

- Use selected sections of the Coursera HTML & CSS Crash Course only.
- Do **not** add CSS Grid, animation libraries, Bootstrap, jQuery, or advanced responsive design as core requirements.
- HTML, CSS, and JavaScript together stay within the broader CS1 front-end lesson budget. Teachers may assign some catch-up lessons as homework instead of class time.
