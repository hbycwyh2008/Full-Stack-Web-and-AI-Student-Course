# Web Basics: HTML and CSS Mini-Unit

Build a simple, complete static webpage across four 90-minute class missions.

## Unit Goal

By the end of this unit, each student should be able to build and submit a small static page with HTML structure, external CSS, container layout, and Flexbox alignment.

Work in one folder — `web-basics-project/` — and grow the same project across all four lessons.

## Lesson Sequence

| Lesson | File | Focus |
|---|---|---|
| 1 | [lesson-01-html-page-structure.md](lesson-01-html-page-structure.md) | HTML document structure, headings, links, images, lists |
| 2 | [lesson-02-css-basics-and-selectors.md](lesson-02-css-basics-and-selectors.md) | External CSS, selectors, colors, fonts, spacing |
| 3 | [lesson-03-box-model-and-layout.md](lesson-03-box-model-and-layout.md) | Box model, centered container, DevTools |
| 4 | [lesson-04-flexbox-mini-project.md](lesson-04-flexbox-mini-project.md) | Flexbox and final mini project |

**Estimated time:** 4 lessons × 90 minutes each.

Each lesson follows the standard classroom flow: Individual Learning → Talk Robin → Group Answer → Teacher Clarification → Mission Task → Independent Rebuild → Evidence to Submit.

See [classroom-flow.md](../../shared/classroom-flow.md) for the full 90-minute block structure.

## Curriculum Reference

This unit is aligned with the Coursera course [HTML & CSS Crash Course](https://www.coursera.org/learn/html--css-crash-course/home/module/1). Each lesson assigns specific sections to read or watch. Course materials are a reference only — mission tasks and evidence requirements are original to this class.

## Final Project

In Lesson 4, choose **one**:

- Simple login page
- Profile card
- Landing page hero section

## Expected Evidence

Submit evidence after every lesson:

- Screenshot or browser preview
- Code committed to GitHub
- Items listed in **Evidence to Submit** in each lesson file

At the end of the unit, your folder should include:

```text
web-basics-project/
├── index.html
├── style.css
└── README.md
```

See [Evidence Levels](../../../evidence-levels.md).

## Optional Extra Lesson

If your teacher assigns it, use one extra 90-minute block for debugging and portfolio polish:

- Fix layout bugs with DevTools
- Improve spacing and readability
- Add the project to your Notion **Learning Projects** section
