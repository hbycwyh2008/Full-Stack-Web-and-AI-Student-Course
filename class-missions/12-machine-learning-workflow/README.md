# Unit 5: Machine Learning Workflow

**Purpose:** Students learn the basic ML pipeline without turning the unit into deep ML theory.

## Core Workflow

```text
Define problem
→ choose features X
→ choose target y
→ train/test split
→ model.fit()
→ model.predict()
→ evaluate
→ inspect errors
→ reflect on limitations
```

## Required Concepts

- problem definition
- features `X`
- target `y`
- train/test split
- `model.fit()`
- `model.predict()`
- accuracy for classification
- MAE / RMSE for regression
- model limitation
- error analysis
- reflection
