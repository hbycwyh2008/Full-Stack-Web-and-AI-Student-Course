# Lesson 8: Notion Portfolio Structure

## Lesson Goal

Build the first version of your Notion portfolio homepage so it can clearly show who you are, what you are learning, and where your GitHub evidence lives.

By the end of this lesson, you should have a Notion page with real sections, not just empty headings.

## Required Resource

Open only the resource named in `Individual Learning`. If the resource is longer than 15 minutes, complete the assigned section in class and finish the rest as homework if your teacher assigns it.

## What to Focus On

Focus on page structure, section layout, and writing real content. Do not publish the page yet — publishing comes in Lesson 9.

## Entry Point Check

Use the first 10 minutes to answer these before new instruction:

- What do I already know that connects to today?
- What file, tool, or concept should I open first?
- What is one question I need answered before the mission?

## Individual Learning

> [!NOTE]
> **One required resource** for this block — see below. Do not browse extra Notion tutorials during class.

Students work individually first.

**Step A — video tutorial:**

1. Open the Class Central classroom: https://www.classcentral.com/classroom/youtube-notion-masterclass-build-a-portfolio-website-from-scratch-for-free-143690/6413e424df7d5
2. Watch from **Intro** through **Add a Contact Form**.
3. **Stop before** **Make the Page Public**. Publishing is Lesson 9.
4. Focus on how Thomas Frank sets up a blank page, builds a hero section, organizes content blocks, and links sections together.

**Step B — map the video to this course:**

The video builds a professional portfolio. Adapt it for this course using [Student Portfolio Template](../../templates/student-portfolio-template.md).

| Course section | What to build |
|---|---|
| **Hero** | Your name, one sentence about who you are, what you build |
| **About Me** | Short bio, CS/AI interests, what you are learning now |
| **Learning Projects** | Placeholder pages or cards for Phase 0 work (README, commits, learning log) |
| **GitHub Evidence** | Link to your course repo — this is your process evidence |
| **Skills** | Tools you have used so far (Git, GitHub, Markdown, Notion) |
| **Reflections** | One short paragraph on what you learned in Phase 0 |

**Individual notes:**

```text
Notion is useful for a portfolio because...
The difference between GitHub evidence and Notion showcase is...
One layout idea I copied from the video is...
One section I renamed for this course is...
My GitHub repo link is...
One thing I still do not understand is...
```

**Student output:** A Notion page with all required sections and real student writing.

## Talk Robin

Each student speaks once before anyone speaks twice.

**Share:**

1. What your portfolio title is
2. One section you built today
3. Where your GitHub repo link appears on the page
4. The difference between GitHub evidence and Notion showcase
5. One confusion or question

**Student output:** Group list of useful layout ideas and unclear questions.

## Group Answer

As a group, prepare one shared answer:

```text
GitHub is for evidence because...
Notion is for showcase because...
A good portfolio hero includes...
Our group still needs help with...
```

**Student output:** One group answer.

## Teacher Clarification

The teacher checks what students already understand before explaining.

**Teacher checks:**

1. Can students explain GitHub vs Notion?
2. Does every page have a GitHub repo link?
3. Are sections filled with real writing, not lorem ipsum?
4. Did anyone try to publish before finishing structure?

**Teacher explanation rule:** Explain only the unclear parts. Do not run a full teacher-demo-first lesson.

The teacher explains only the common stuck points before the mission task.

## Mission Task

Students complete the main task.

**Mission resource, if needed:** [Student Portfolio Template](../../templates/student-portfolio-template.md)

**Task:**

1. Create or open your Notion portfolio page.
2. Add a clear portfolio title at the top.
3. Build all six required sections: Hero, About Me, Learning Projects, GitHub Evidence, Skills, and Reflections.
4. Paste your GitHub course repo URL into the **GitHub Evidence** section.
5. Write at least one real sentence under every heading — no empty placeholders.

**Mission output:**

- Notion page with all six sections
- GitHub repo link visible on the page
- Real student writing in every section

## Independent Rebuild

> [!IMPORTANT]
> Independent work: close the Class Central video, notes, and AI tools before this block.

Students repeat the workflow independently **without looking at the tutorial**.

This is not a delete-and-redo task. Stay on the same Notion page and make one meaningful improvement.

**Independent rebuild task:**

1. Open your Notion portfolio without the video.
2. Add or improve one section using your own words — for example, expand **Reflections** or add a second bullet under **Skills**.
3. Confirm your GitHub repo link still works.
4. Be ready to explain your page structure orally if called.

**Exit prompts:**

```text
My portfolio title is...
GitHub evidence lives in this section because...
Notion showcase lives in these sections because...
One thing I can now do without the tutorial is...
One thing I still need help with is...
```

**Oral check if called:** Explain Hero → GitHub Evidence → Learning Projects using your own Notion page.

Close full-solution references before this block. You may use your own short checklist, but do not copy a completed answer.

## Evidence to Submit

1. Screenshot of your Notion portfolio homepage showing all required sections
2. Screenshot or note showing your GitHub repo link on the page
3. One sentence: "GitHub is my evidence because... Notion is my showcase because..."

## Success Criteria

You are successful if:

1. Your Notion page has a clear portfolio title.
2. Your page includes Hero, About Me, Learning Projects, GitHub Evidence, Skills, and Reflections.
3. Your GitHub repo link appears on the page.
4. Your sections contain real student writing, not empty placeholders.
5. You can explain the difference between GitHub evidence and Notion showcase.

## Common Problems

| Problem | Try first |
|---|---|
| My page looks empty | Add short real sentences under each heading. |
| I only copied the video sections | Rename sections so they fit this course. |
| I cannot find my GitHub repo link | Open GitHub, go to your course repo, and copy the browser URL. |
| I want to publish immediately | First finish the structure and check your links. Publishing comes next lesson. |

## Fast Track / Support Track

Fast track:

If most students complete this lesson in about 45 minutes, continue directly into Lesson 9 during the same 90-minute block.

Use this only if students have:

1. Built all required sections.
2. Added their GitHub repo link.
3. Written real content in their own words.
4. Completed the independent rebuild without watching the tutorial again.

If more than one third of the class is still missing the page structure, do not start publishing. Use the remaining time for page organization, link checks, and oral explanation.

Support track:

- Complete the smallest working version first.
- Ask for a hint after you can show what you tried.
- Submit honest evidence of progress if the full mission is not finished.
