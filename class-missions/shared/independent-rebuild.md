# Independent Rebuild

Independent rebuild proves you can recreate the core pattern without copying a finished solution.

## Rules

- Close full-solution references.
- Do not copy from AI, classmates, or the finished follow-along code.
- You may use your own short checklist if the mission allows it.
- Hand-type the core pattern again in the folder named by the mission.
- Add a short `REBUILD.md` explaining what you rebuilt and what you still need to practice.

## Evidence

Submit the rebuild folder, a commit link, and a short explanation in your own words.
