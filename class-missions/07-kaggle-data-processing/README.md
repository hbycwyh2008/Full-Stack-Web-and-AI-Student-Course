# Unit 4: Kaggle, pandas, and Data Processing

**Purpose:** Students learn how data becomes input for machine learning.

Students repeatedly practice this workflow:

```text
Load data → inspect rows → inspect columns → check missing values
→ understand features and target → prepare data for modeling
```

## Core Commands

- Kaggle Python
- Kaggle Pandas
- CSV reading
- pandas `DataFrame`
- `head()`
- `columns`
- `info()`
- `describe()`
- `isnull().sum()`
- `value_counts()`
- selecting features
- understanding target
- simple visualization if useful

## Suggested Lessons

| Lesson | Focus | Evidence |
|---|---|---|
| 1 | Kaggle notebook workflow | notebook screenshot/export |
| 2 | load CSV and inspect rows/columns | inspection notes |
| 3 | missing values and value counts | missing-value summary |
| 4 | features and target | `X`/`y` explanation |
| 5 | no-notes inspection report | data workflow evidence |
