# Student GitHub Repository Guide

Your personal GitHub repository stores your learning process. This course repo is read-only.

## Recommended Repository Name

`[studentName]-Full-Stack-Web-and-AI-Application`

## Recommended Folder Structure

```text
profile/
reflections/
github-notion/
ai-literacy/
html-css-basics/
javascript-basics/
react-basics/
nextjs-frontend/
fastapi-backend/
nextjs-fastapi-integration/
capstone/
portfolio/

optional-ai-math-bridge/
```

## What Goes in Each Phase Folder

Each phase folder should include useful evidence, not empty files.

- Code or artifact
- README or short explanation
- Screenshots when helpful
- Reflection notes
- AI usage note if AI helped
- Meaningful commits

## Good Commit Messages

Use messages that explain the change:

- `Add GitHub profile README draft`
- `Build HTML form structure`
- `Fix JavaScript button click bug`
- `Create first React component`
- `Connect Next.js page to FastAPI route`
- `Document AI usage for capstone revision`

Avoid `update`, `final`, `stuff`, or one giant commit for a whole project.

## README Checklist

A project README should answer:

- What did I build?
- How do I run it?
- What files matter most?
- What bug or revision did I handle?
- What did I learn?
- Did I use AI? If yes, how?

## Evidence Reminder

Daily Evidence is small: a link, screenshot, short note, or commit.

Phase Checkpoint Evidence includes a working artifact, README, commit history, reflection, and AI usage note if used.

Final Project Evidence includes live demo, full README, technical report, reflection, revision history, portfolio page, and AI usage documentation.
