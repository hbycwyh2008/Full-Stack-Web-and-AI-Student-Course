# GitHub Repo Setup Guide

Your class work goes in your personal GitHub repository, not in this course repo.

## Create Your Repo

1. Sign in to GitHub.
2. Create a new public repository.
3. Use the name your teacher gives you, usually `[studentName]-Full-Stack-Web-and-AI-Application`.
4. Add a `README.md`.
5. Commit your first change.

## Recommended Folders

```text
profile/
reflections/
ai-literacy/
html-css-basics/
javascript-basics/
react-basics/
nextjs-frontend/
fastapi-backend/
full-stack-integration/
capstone/
portfolio/
```

## Good Commit Messages

- `Add first README`
- `Build HTML profile form`
- `Fix FastAPI route error`
- `Document AI usage for checkpoint`

Avoid messages like `final`, `stuff`, or `update`.
