# Submission Guide

Submit exactly what the class mission asks for.

## Before You Submit

- [ ] The link opens.
- [ ] The work is in your personal GitHub repo.
- [ ] Your commit history shows your process.
- [ ] Your README or note explains what you did.
- [ ] Your AI usage note is included if AI helped.

## Daily Submission

Submit a repo link, screenshot, short note, or small commit from today's mission.

## Phase Checkpoint Submission

Submit the working artifact, README, commit history, reflection, and AI usage note if used.

## Final Project Submission

Submit the live demo, full README, technical report, reflection, revision history, portfolio page, and AI usage documentation.
