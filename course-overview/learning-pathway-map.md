# Learning Pathway Map

The course is organized into eight CS1 units. Follow them in order unless your teacher marks something as optional.

| Unit | Main focus | Student outcome |
|---|---|---|
| 0. Tool Layer | GitHub, Markdown, Notion Web | Documentation, submission, showcase habits |
| 1. HTML/CSS/JS Crash Foundation | Minimal webpage and DOM interaction | Mini AI App Mockup |
| 2. React Frontend Basics | React + Vite app interface | AI app frontend pattern |
| 3. Python Foundations | Practical programming | Python tasks and tests |
| 4. Kaggle/Data | pandas data inspection workflow | Data inspection report |
| 5. ML Workflow | Simple models and evaluation | Titanic training and House Price regression |
| 6. FastAPI for AI Apps | JSON backend prediction flow | React calls Python backend |
| 7. Final AI Web Apps | House Price and MNIST | Final project evidence |

## Optional / Extension

- Figma: lightweight design planning or teacher-selected design sprint.
- AI Literacy: responsible AI discussions and reflection.
- AI Math Bridge: optional extension for vectors, matrices, and similarity.
- Next.js, databases, deployment, RAG, and Cursor deep dives: later-course enrichment only.
