# Learning Pathway Map

This is the main course path. Follow it in order unless your teacher marks something as optional.

| Phase | Main focus | Student outcome |
|---|---|---|
| 1. GitHub + Notion | Repo, README, commits, portfolio | Personal course repo and Notion portfolio |
| 2. AI Literacy | Responsible AI use | AI reflection and policy understanding |
| 3. HTML/CSS Basics | Page structure and styling | Simple web page or form |
| 4. JavaScript Basics | DOM, events, functions | Interactive browser page |
| 5. React Basics | Components, props, state | Small React app |
| 6. Next.js Frontend | App Router, pages, layouts | Next.js frontend project |
| 7. FastAPI Backend | APIs, routes, models | Working FastAPI backend |
| 8. Next.js + FastAPI Integration | Fetch and CORS | Frontend talks to backend |
| 9. Cursor-assisted Capstone | AI-assisted workflow after stack basics | Capstone prototype with documented AI use |
| 10. Final Portfolio Showcase | Present and explain | Portfolio page and final presentation |

## Optional / Extension

- Figma: lightweight design planning or teacher-selected design sprint.
- AI Math Bridge: optional extension for vectors, matrices, and similarity.
- RAG concepts: introduced near the capstone only when students need document-grounded Q&A.
- TypeScript: introduced lightly when Next.js examples require it.
