# Course Overview

**CS1: Web, Python, and AI Application Foundations** is a portfolio-first, evidence-based, mastery-focused course.

CS1 is no longer only a Web development course. It uses Web development as the application layer while students build foundations in tools, frontend programming, Python, data processing, machine learning workflow, and AI Web App projects.

## Learning Path

```text
Tools → HTML/CSS/JS → React + Vite → Python
→ Kaggle/Data → Machine Learning Workflow
→ FastAPI for AI Apps → AI Web App Projects
```

## Course Goals

- Use GitHub, Markdown, commits, Notion Web, reflection, and AI use logs for evidence.
- Build enough HTML/CSS/JavaScript to understand webpages and prepare for React.
- Build React + Vite interfaces for AI app inputs and outputs.
- Use Python for practical programming, debugging, file reading, and simple tests.
- Inspect datasets with Kaggle and pandas.
- Explain features `X`, target `y`, train/test split, predictions, basic evaluation, limitations, and error analysis.
- Connect React to FastAPI so Python functions or trained models can return prediction JSON.
- Present House Price and MNIST project evidence with README, testing table, reflection, and AI use log.

## Final Projects

**Core Final Project:** House Price Prediction Web App. Students build a React form, FastAPI backend, trained regression model, prediction result display, testing table, README, reflection, and AI use log.

**Showcase Project:** MNIST Digit Recognition Web App. The teacher may provide complex image preprocessing scaffold; students focus on the React UI, backend call, result display, testing, README, reflection, and limitations.

## AP CSP Alignment

CS1 supports AP CSP without becoming only test prep. Students practice input, output, lists/arrays, student-developed procedures, procedure calls, selection, iteration, testing, program purpose, data use, and responsible computing reflection.

A machine learning model cannot replace the student's own explainable algorithm. ML projects still need student-written logic such as input validation, result interpretation, risk/category classification, testing functions, or prediction explanations.
