# Course Pacing Guide

Use this as a simple pacing map. Adjust dates for your school calendar.

| Phase | Suggested focus | Evidence level |
|---|---|---|
| 1. GitHub + Notion | Repos, commits, portfolio setup | Daily + checkpoint |
| 2. AI Literacy | Responsible AI and reflection | Daily |
| 3. HTML/CSS Basics | Structure and styling | Checkpoint |
| 4. JavaScript Basics | DOM and events | Checkpoint |
| 5. React Basics | Components, props, state | Checkpoint |
| 6. Next.js Frontend | App Router, pages, layouts | Checkpoint |
| 7. FastAPI Backend | API routes and models | Checkpoint |
| 8. Next.js + FastAPI Integration | Fetch, CORS, full-stack flow | Checkpoint |
| 9. Cursor-assisted Capstone | Capstone with documented AI assistance | Final project |
| 10. Final Portfolio Showcase | Presentation and portfolio polish | Final project |

Optional / teacher-selected extensions: Figma, AI Math Bridge, extra database practice, and RAG concepts near the capstone.
