# Course Pacing Guide

Use this as a simple pacing map. Adjust dates for your school calendar.

| Unit | Suggested focus | Evidence level |
|---|---|---|
| 0. Tool Layer | GitHub, Markdown, Notion, AI use log | Daily + checkpoint |
| 1. HTML/CSS/JS Crash Foundation | Mini AI App Mockup | Checkpoint |
| 2. React Frontend Basics | React + Vite AI interface | Checkpoint |
| 3. Python Foundations | Python tasks, debugging, tests | Checkpoint |
| 4. Kaggle/Data | pandas inspection workflow | Checkpoint |
| 5. ML Workflow | Titanic training, House Price regression | Checkpoint |
| 6. FastAPI for AI Apps | Prediction endpoint and JSON flow | Checkpoint |
| 7. Final AI Web Apps | House Price app and MNIST showcase | Final project |

Unit 1 should stay within 6–9 lessons. Unit 2 uses React + Vite only. Optional / teacher-selected extensions: Figma, AI Literacy, AI Math Bridge, Next.js, extra database practice, and Cursor deep dives.
