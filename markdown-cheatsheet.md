# Markdown Cheatsheet

Use Markdown in GitHub README files and reflections.

## Headings

```md
# Big Title
## Section
### Small Section
```

## Lists

```md
- Item
- Item

1. First
2. Second
```

## Links and Images

```md
[Link text](https://example.com)
![Image description](image.png)
```

## Code

```md
`one line of code`
```

Use three backticks for a code block.

## Checklist

```md
- [ ] Not done
- [x] Done
```
