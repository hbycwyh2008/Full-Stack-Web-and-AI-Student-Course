# Student Troubleshooting Guide

Debugging is part of learning. Do not panic when something breaks.

## First Checks

- [ ] Did I open the correct folder?
- [ ] Did I save the file?
- [ ] Did I run the correct command?
- [ ] Did I read the error message?
- [ ] Did I check spelling, file names, and capitalization?

## When Code Does Not Work

1. Read the error message.
2. Find the file and line it mentions.
3. Undo only your last small change if needed.
4. Compare with the mission checklist.
5. Make one fix at a time.
6. Commit when the fix works.

## How to Ask for Help

Say:

```text
I expected...
I got...
The error says...
I already tried...
Here is the file or screenshot...
```

## AI Debugging Rule

Ask AI to explain the error or suggest a next step. Do not ask AI to finish the whole assignment for you.
