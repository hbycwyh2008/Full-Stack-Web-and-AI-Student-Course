# Evidence Levels

This course grades learning evidence, not only whether code runs once.

## Daily Evidence

Daily Evidence is lightweight proof from one class.

Submit one or more of these when the mission asks:

- Repo link
- Screenshot
- Short note
- Small commit
- Link to the exact file you changed

## Phase Checkpoint Evidence

Phase Checkpoint Evidence proves you completed a larger pattern.

Submit:

- Working project or artifact
- README
- Commit history
- Short reflection
- AI usage note if AI was used

## Final Project Evidence

Final Project Evidence proves capstone-level mastery.

Submit:

- Live demo
- Full README
- Technical report
- Reflection
- Revision history
- Portfolio page
- AI usage documentation

## Mastery Reminder

You should be able to explain, rebuild, debug, modify, and apply the pattern. If you cannot explain it, the evidence is not complete yet.
