# AP CSP Alignment

CS1 supports AP CSP without becoming only AP CSP test preparation.

## Big Ideas Supported

| AP CSP area | Where CS1 supports it |
|---|---|
| Creative Development | Mini AI App Mockup, React interface, House Price app, MNIST showcase |
| Data | Kaggle notebooks, pandas inspection, features `X`, target `y`, missing values |
| Algorithms and Programming | JavaScript functions, Python functions, lists, selection, iteration, testing |
| Computer Systems and Networks | React `fetch()`, JSON request/response, FastAPI routes, CORS basics |
| Impact of Computing | AI use logs, model limitation reflection, responsible computing discussion |

## Create-Style Practice

Students practice input, output, list/array, student-developed procedure, procedure call, selection, iteration, testing, program purpose, data use, and responsible computing reflection.

## Important ML Rule

A machine learning model cannot replace the student's own explainable algorithm.

If a project uses ML, students still need student-written logic they can explain clearly, such as input validation, recommendation logic, result interpretation, risk/category classification, testing function, or prediction explanation.
