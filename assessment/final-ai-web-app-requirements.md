# Final AI Web App Requirements

CS1 has two final project levels.

## Core Final Project: House Price Prediction Web App

Students build:

- React + Vite frontend form
- FastAPI backend
- trained regression model
- prediction result display
- testing table
- README
- reflection
- AI use log

Students must explain user inputs, model prediction, React-to-FastAPI data flow, returned result, model limitations, and student-written logic.

## Showcase Project: MNIST Digit Recognition Web App

Teacher-provided scaffold may include canvas drawing, image upload, resizing, grayscale conversion, normalization, model input shape conversion, model loading, and prediction endpoint structure.

Students are responsible for React UI, backend call, prediction display, confidence/top result if available, testing digits, README, reflection, and explaining failure cases.

## Final Submission Checklist

```text
[ ] GitHub project link
[ ] React frontend screenshot
[ ] FastAPI endpoint test screenshot
[ ] End-to-end prediction screenshot
[ ] Testing table
[ ] README
[ ] Reflection
[ ] AI use log
[ ] AP CSP-style explanation of input, output, procedure, selection, iteration, list/data use, and testing
[ ] Model limitation and responsible computing reflection
```
